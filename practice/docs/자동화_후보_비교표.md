## 후보 개요

| 번호 | 업무명 | 현재 프로세스 |
|---|---|---|
| 1 | 일일 인원현황 보고 | ERP 근태 다운로드 → 데이터 정리 → 카톡방 메시지 작성/공유 → 엑셀 생성 → 메일 발송 |
| 2 | 일일 일용직 투입현황 보고 | 일용투입현황 수기 접수 → 엑셀 입력 → 화면 캡처 → 메일 본문 삽입 & 파일 첨부 보고 |
| 3 | 연차관리 | (현행) ERP 근태 입력 → 연차 현황 추출 → 회계연도 기준 잔여연차 엑셀에 수동 반영 / (구상 중) Claude Code로 ERP 근태 엑셀만 지정 폴더에 넣으면 기존 잔여연차 관리 엑셀에 자동 매핑·최신화 |

## 평가

| 번호 | 업무명 | 빈도 | 손이 가는 정도(귀찮음) | AI 적합도 |
|---|---|---|---|---|
| 1 | 일일 인원현황 보고 | 높음 (매일) | 보통 — 다운로드·정리·엑셀·메일은 단순 반복이나, 카톡 메시지 작성은 문구 판단이 약간 개입 | 대체로 적합 — 데이터 정리/엑셀 생성/메일 발송은 규칙적 반복 작업이라 자동화 용이, 카톡 메시지 문구만 템플릿화 필요 |
| 2 | 일일 일용직 투입현황 보고 | 높음 (매일) | 높음 — 수기 접수→입력→캡처→본문 삽입까지 수작업 단계가 많고 반복적으로 번거로움 | 적합 — 접수 데이터를 정형화할 수 있으면 입력·문서화·보고 전 과정이 규칙 기반이라 자동화 적합도 높음 |
| 3 | 연차관리 | 낮음 (회계연도 기준, 비정기/월 단위 수준) | 보통 — 발생 빈도는 낮지만 매핑 실수 시 파급(급여·인사 이슈)이 커서 심리적 부담은 있음 | 매우 적합 — 근태 데이터 ↔ 잔여연차 엑셀 매핑은 순수 규칙 기반 로직이라 AI/자동화가 특히 잘 맞음 (이미 Claude Code 활용안 구체화됨) |

## 참고
- "AI 적합도"는 작업이 규칙적·반복적일수록 높고, 문구 톤 조절이나 예외 판단, 책임 소재가 큰 부분이 섞여 있으면 상대적으로 낮게 평가했습니다.
- 아직 우선순위는 정하지 않았습니다. 추가로 비교하고 싶은 기준(예: 자동화 난이도, 예상 절감 시간, 실패 시 리스크)이 있으면 표에 열을 추가할 수 있습니다.

## 부분 자동화 제안 — 후보1 (일일 인원현황 보고)

세 후보 중 AI 적합도가 상대적으로 가장 낮게 평가된 후보1을 단계별로 쪼개면, 실제로 판단이 필요한 부분은 일부에 불과합니다.

| 단계 | 성격 | 담당 |
|---|---|---|
| ERP 근태 다운로드 | 매일 동일한 절차, 규칙적 | **AI/자동화** |
| 데이터 정리 (엑셀 가공) | 규칙 기반 (특정 열 추출, 합계 계산 등) | **AI/자동화** |
| 카톡 메시지 — 숫자·양식 채우기 | 매일 포맷 동일, 숫자만 교체 | **AI/자동화** (템플릿 자동 생성) |
| 카톡 메시지 — 특이사항 언급/톤 조절 | 결근율 급증, 민감한 인원 이슈 등 예외 판단 | **사람** |
| 엑셀 생성 및 메일 발송 | 규칙 기반, 정형 포맷 | **AI/자동화** |

**정리**: 다운로드 → 정리 → 엑셀 생성 → 메일 발송은 AI가 전담 가능. 카톡 메시지도 정형 문구(출근/결근 인원수 등)는 AI가 초안을 자동 생성하고, 사람은 이상치가 있을 때만 문구를 검토·수정 후 전송하는 구조로 가면 후보1도 대부분 자동화할 수 있습니다.

## 효과 × 난이도 2×2 매트릭스

| | **난이도 낮음** | **난이도 높음** |
|---|---|---|
| **효과 높음** | **★ 후보1 — 일일 인원현황 보고**<br>매일 반복, 입력이 정형화(ERP 엑셀)돼 있고 리스크도 낮아 바로 시작하기 좋음 | **후보2 — 일용직 투입현황 보고**<br>매일 반복이라 효과는 크지만, 수기 접수 자료를 정형화하는 과정이 추가로 필요해 준비 비용이 있음 |
| **효과 낮음** | *(해당 없음)* | **후보3 — 연차관리**<br>발생 빈도가 낮아 체감 효과는 작지만, 회계연도·이월·비례연차 등 매핑 규칙이 복잡하고 실수 시 파급력이 커서 난이도가 높음 |

**한눈에 요약**
- **후보1**: 효과 높음 + 난이도 낮음 → 지금 진행 중인 프로젝트 대상과 일치
- **후보2**: 효과 높음 + 난이도 높음 → 두 번째 프로젝트 후보로 유력
- **후보3**: 효과 낮음 + 난이도 높음 → 우선순위상 가장 나중, 신중한 검증 필요
