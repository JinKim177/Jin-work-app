# App 자동화 흐름도

**App 개요**: 매일 일일근태현황 엑셀파일을 다운받아 팀장·팀원별로 정리하여, 카톡으로 보고할 수 있는 요약보고자료를 만들어주는 도구

작성일: 2026-07-22

---

## 입력 → 처리 → 출력

```
[입력]
일일근태현황 엑셀 파일 (ERP에서 다운로드한 원본 파일)
   ↓
[처리 1] 엑셀 파일 불러오기
   ↓
[처리 2] 필요한 열만 선택 (이름, 소속팀, 직책(팀장/팀원 여부), 근태구분, 사유 등)
   ↓
[처리 3] 빈 행 제거
   ↓
[처리 4] 중복 행 제거
   ↓
[처리 5] 1차 구분: 직책 기준으로 팀장근태 / 팀원근태 분리
   ↓
        (아래 처리 6~9는 팀장근태·팀원근태 양쪽 모두 동일하게 거침 — 한쪽만 거치지 않음)
   ↓
[처리 6] 근태 종류별로 그룹핑 (연차, 산재, 결근, 지각 등)
   ↓
[처리 7] 근태 종류별 인원수 집계
   ↓
[처리 8] 근태 종류별 소속팀 세부 인원 정리
   ↓
[처리 9] 근태 종류별 요약 문구 생성
        예: "연차 2명(관리팀1, 품질팀1), 산재 1명(상자생산팀)"
   ↓
[처리 10] 팀장근태 요약 + 팀원근태 요약 병합
   ↓
[처리 11] 카톡 발송용 포맷으로 변환
   ↓
[사람 확인] 산재·장기결근 등 민감할 수 있는 항목의 표현이 적절한지 검토 후 승인
   ↓
[출력]
카톡방에 바로 붙여넣을 수 있는, 팀장근태/팀원근태로 구분되고
근태 종류별 인원수(소속팀 포함)가 표기된 요약 보고 텍스트 (최종 1개)
```

## 단계별 설명

| 구분 | 단계 | 담당 | 하는 일 (한 단계 = 한 가지 일) |
|---|---|---|---|
| 입력 | - | - | 일일근태현황 엑셀 파일 |
| 처리 1 | 파일 불러오기 | AI | 엑셀 파일을 열어 데이터로 읽어들임 |
| 처리 2 | 열 선택 | AI | 이름·소속팀·직책·근태구분·사유 등 필요한 열만 추림 |
| 처리 3 | 빈 행 제거 | AI | 값이 없는 빈 행을 제거 |
| 처리 4 | 중복 행 제거 | AI | 동일하게 중복된 행을 제거 |
| 처리 5 | 1차 구분 | AI | 직책 기준으로 팀장근태 / 팀원근태를 분리 |
| 처리 6 | 2차 구분 | AI | (양쪽 모두) 근태 종류(연차, 산재, 결근 등)별로 그룹핑 |
| 처리 7 | 인원 집계 | AI | (양쪽 모두) 근태 종류별 인원수를 셈 |
| 처리 8 | 소속팀 세부 정리 | AI | (양쪽 모두) 근태 종류별로 어느 팀에서 몇 명인지 정리 (예: 관리팀1, 품질팀1) |
| 처리 9 | 요약 문구 생성 | AI | (양쪽 모두) "연차 2명(관리팀1, 품질팀1)" 형식으로 문구 생성 |
| 처리 10 | 병합 | AI | 팀장근태 요약과 팀원근태 요약을 하나로 합침 |
| 처리 11 | 포맷 변환 | AI | 병합된 내용을 카톡 발송용 텍스트 형식으로 바꿈 |
| 사람 확인 | 표현 검토 | 사람 | 민감할 수 있는 항목(산재, 장기결근 등)의 표현이 적절한지 최종 확인 |
| 출력 | - | - | 카톡 공유용 요약 보고 텍스트 (하나만 존재) |

## 참고
- 각 처리 단계는 "한 단계 = 한 가지 일"로 쪼개져 있어, 이후 자동화 구현 시 단계별로 하나씩 테스트하기 쉽습니다.
- 처리 6~9는 팀장근태·팀원근태 양쪽에 반드시 동일하게 적용되며, 한쪽이라도 건너뛰면 안 됩니다. 두 그룹은 처리 10에서 비로소 하나로 합쳐집니다.
- 출력은 항상 하나입니다. 처리 5(1차 구분)에서 갈라진 두 경로가 중간에 각자 출력으로 빠지는 일이 없어야 합니다.
- 처리 9(요약 문구 생성) 형식은 예시이며, 실제 근태 종류(연차·산재·결근·지각·조퇴 등) 목록에 맞게 조정이 필요합니다.
- 처리 11(포맷 변환) 이후, 출력 전에 "사람 확인" 단계를 반드시 거칩니다. 민감한 근태 항목이 자동으로 발송되지 않도록 하기 위함입니다.
