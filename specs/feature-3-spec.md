# Feature 3 명세 — 파일 자동 인식 + 요약 텍스트 생성 연결

근거 문서: [App_기획서.md](App_기획서.md), [feature-1-spec.md](feature-1-spec.md), [feature-2-spec.md](feature-2-spec.md)

## 무엇을 하는 기능인가

지정 폴더에서 오늘 날짜의 근태 엑셀 파일을 자동으로 찾아(Feature 2), 찾은 파일을 그대로 근태 요약 텍스트 생성(Feature 1)에 넘겨서, 폴더 확인부터 카톡용 요약 텍스트 출력까지 한 번에 이어지게 하는 연결 기능.

## 입력

- 감시 대상 폴더 경로 (예: `inputs/`)
- 찾을 파일명 패턴: `ERP-일일근태현황(MM.DD).xlsx`
- 오늘 날짜 (시스템 날짜를 그대로 사용, 별도 입력 없음)

## 동작

1. 시스템의 오늘 날짜(MM.DD)를 확인한다.
2. 지정 폴더 안의 파일 목록에서 파일명 패턴에 맞는 xlsx 파일만 추린다.
3. 그중 파일명 속 날짜(MM.DD)가 오늘 날짜와 정확히 일치하는 파일만 후보로 남긴다. (날짜가 다른 파일은 어제 것이든 뭐든 후보에서 제외 — 재처리 방지)
4. 후보가 없으면: "오늘(MM.DD) 근태 파일을 아직 찾지 못했습니다" 같은 안내 메시지만 출력하고 에러 없이 조용히 종료한다.
5. 후보가 여러 개면(같은 날짜 파일이 중복으로 들어온 경우) 파일 수정 시각이 가장 최근인 것 하나를 고른다.
6. 선택된 파일 경로를 Feature 1(근태 요약 텍스트 생성)에 그대로 전달한다.
7. Feature 1이 만든 카톡용 요약 텍스트를 화면에 출력한다.

## 출력

- 오늘 날짜의 근태 파일을 찾은 경우: Feature 1이 생성한 카톡용 요약 텍스트 1개 (화면 출력)
- 오늘 날짜의 근태 파일을 못 찾은 경우: 안내 메시지 1줄 (정상 종료, 에러 아님)
