# Feature 2 명세 — 근태 엑셀 파일 자동 인식

근거 문서: [App_기획서.md](App_기획서.md) (입력 — "전달 방식: 지정 폴더에 파일을 넣으면 자동 인식")

## 무엇을 하는 기능인가

지정된 폴더를 확인해서, 그 안에 있는 일일근태현황 엑셀 파일 중 오늘 처리해야 할 파일 하나의 경로를 찾아주는 기능.

## 입력

- 감시 대상 폴더 경로 (예: `inputs/`)
- 찾을 파일명 패턴 (예: `ERP-일일근태현황(*).xlsx`)

## 동작

1. 지정 폴더 안의 파일 목록을 읽는다.
2. 파일명 패턴에 맞는 xlsx 파일만 추린다.
3. 해당하는 파일이 여러 개면, 가장 최근에 수정된(또는 파일명의 날짜가 가장 최신인) 파일 하나를 고른다.
4. 해당하는 파일이 하나도 없으면 "파일 없음" 상태로 처리한다.
5. 찾은 파일의 전체 경로를 결과로 돌려준다.

## 출력

- 조건에 맞는 근태 엑셀 파일의 경로 문자열 하나. (Feature 1의 입력으로 그대로 넘겨 쓸 수 있음)
- 파일이 없을 경우: "파일 없음" 상태값 (에러로 죽지 않고 이 상태를 알려주기만 함)
