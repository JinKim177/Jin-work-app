# Feature 1 명세 — 근태 요약 텍스트 생성

근거 문서: [App_기획서.md](App_기획서.md), [App_자동화_흐름도.md](App_자동화_흐름도.md)

## 무엇을 하는 기능인가

일일근태현황 엑셀 파일 하나를 읽어, 팀장근태/팀원근태로 나누고 근태 종류별 인원수(소속팀 포함)를 정리한 카톡 붙여넣기용 요약 텍스트 하나를 만드는 기능.

## 입력

- 일일근태현황 엑셀 파일 경로 (xlsx, 예: `ERP-일일근태현황(07.23).xlsx`)
- 시트명: `HuDut020ControlDB`
- 사용 열(2행 헤더 기준): B 근태일, F 성명, H 부서명, I 근태코드, M 비고(사유)

## 동작

1. 엑셀 파일을 열어 지정 시트를 읽는다 (2행을 헤더로, 3행부터 데이터로 취급).
2. 필요한 열(B, F, H, I, M)만 남긴다. 근태일(B)은 화면에 직접 표시하진 않지만 4단계 중복 판단과 9단계 제목 날짜 계산에 쓴다.
3. 빈 행을 제거한다.
4. 중복 행을 제거한다. 근태일까지 포함해서 비교한다 — 같은 사람이 같은 근태코드·같은 사유라도 날짜가 다르면 별개 건으로 취급한다 (다른 날 근태가 중복으로 오인되어 지워지지 않도록).
5. H열(부서명) 값이 "팀장"으로 끝나면 팀장근태, 그 외는 팀원근태로 분리한다.
6. 팀장근태·팀원근태 각각에 대해:
   a. 근태코드(I열) 기준으로 그룹핑한다.
   b. 근태 종류별 인원수를 센다.
   c. 근태 종류별로 어느 팀에서 몇 명인지 정리한다. 이때 부서명에 포함된 "(발안)", "-발안" 표기는 이미 다 아는 정보이므로 생략한다 (예: "상자고객감동팀(발안)"→"상자고객감동팀", "관리팀-발안"→"관리팀").
   d. 요약 문구를 만든다.
      - 팀원근태: "연차 2명(관리팀1, 품질팀1)" 형식 — 팀명 뒤에 그 팀 인원수를 붙인다.
      - 팀장근태: "휴가 3명(상자영업팀장, 상자고객감동팀장, 상자생산팀장)" 형식 — 팀장 부서는 팀당 항상 1명뿐이므로, 팀명 뒤에 인원수를 붙이지 않는다.
7. 팀장근태 요약과 팀원근태 요약을 하나로 합친다.
8. 전체 근태 인원(팀장근태+팀원근태 합계)을 근태코드별로 묶어 "근태요약" 블록을 만든다.
   - 근태코드는 원래 값 그대로 표기한다 (임의로 축약하지 않음).
   - "총 N명" 다음 줄부터, 근태코드별 "코드N" 항목을 4개씩 줄바꿈해서 괄호로 묶는다.
9. 카톡 붙여넣기용 텍스트 형식으로 변환한다.
   - 제목: "YY년M월D일(요일 한 글자) 발안공장 일일근태보고" (예: "26년7월23일(목) 발안공장 일일근태보고"). 이때 날짜는 실행 시각(오늘)이 아니라 데이터의 실제 근태일(B열, 첫 유효 값)을 기준으로 한다 — 지난 날짜 파일을 뒤늦게 처리해도 제목이 파일 내용과 어긋나지 않도록 하기 위함. 근태일을 읽을 수 없으면 오늘 날짜로 대체한다.
   - 전체 구성은 번호를 매긴 3개 블록 순서로 고정한다: "1. 근태요약" → "2. 팀장근태" → "3. 팀원근태"
   - 팀장근태/팀원근태 각 섹션 안에서, 근태 종류별 요약 문구는 한 줄에 몰아 쓰지 않고 종류마다 줄을 나눠서 표기한다.

## 출력

제목 + "1. 근태요약"(전체 인원·유형 한눈에 보기) + "2. 팀장근태" + "3. 팀원근태"로 구성된, 카톡방에 사람이 직접 붙여넣을 수 있는 요약 보고 텍스트 1개 (문자열). 제목·번호·팀장근태 표기·부서명 표기는 위 8~9단계의 규칙을 항상 그대로 따른다 (예외 없이 적용).
