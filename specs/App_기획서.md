## 목표

매일 일일근태현황 엑셀 파일을 받아 팀장근태/팀원근태로 나누고 근태 종류별 인원수(소속팀 포함)로 정리해서, 카톡방에 바로 붙여넣을 수 있는 요약 보고 텍스트를 만들어준다.

## 입력

- 일일근태현황 엑셀 파일 (ERP에서 다운로드한 원본 파일, xlsx)
- 전달 방식: 지정 폴더에 파일을 넣으면 자동 인식
- 파일명 예시: `ERP-일일근태현황(07.23).xlsx`
- 시트명: `HuDut020ControlDB`
- 1행은 영문 필드 코드, **2행이 실제 한글 헤더**, **3행부터 데이터**
- 열 구성 (2행 헤더 기준)

| 열 | 헤더명 | 비고 |
|---|---|---|
| B | 근태일 | |
| C | 요일 | |
| D | 휴일구분 | |
| E | 사번 | |
| F | 성명 | |
| G | 부서코드 | |
| H | 부서명 | 팀장/팀원 구분에 사용 (아래 단계5 참고) |
| I | 근태코드 | 근태 종류 (연차, 휴가, 병가, 산재, 결근, 지각, 조퇴, 육아휴직, 출산휴가, 공상, 특휴, 훈련, 교육 등) |
| J | 근태횟수 | |
| K | 근태시간 | |
| L | 근태분 | |
| M | 비고 | 사유 |

## 단계

1. 엑셀 파일 불러오기
2. 필요한 열만 선택 (F 성명, H 부서명, I 근태코드, M 비고(사유) 등)
3. 빈 행 제거
4. 중복 행 제거
5. 1차 구분: H열(부서명) 값이 **"팀장"으로 끝나면 팀장근태**, 그 외는 전부 팀원근태로 분리 (예: "상자영업팀장"→팀장, "상자고객감동팀(발안)"·"관리팀-발안"·"공무팀"→팀원)
6. 근태 종류별로 그룹핑 (연차, 휴가, 병가, 산재, 결근, 지각, 조퇴, 육아휴직, 출산휴가, 공상, 특휴, 훈련, 교육 등) — 팀장근태·팀원근태 양쪽 모두 적용
7. 근태 종류별 인원수 집계 — 양쪽 모두 적용
8. 근태 종류별 소속팀 세부 인원 정리 — 양쪽 모두 적용
9. 근태 종류별 요약 문구 생성 (예: "연차 2명(관리팀1, 품질팀1), 산재 1명(상자생산팀)") — 양쪽 모두 적용
10. 팀장근태 요약 + 팀원근태 요약 병합
11. 카톡 발송용 포맷으로 변환
12. (사람) 산재·장기결근 등 민감할 수 있는 항목의 표현이 적절한지 검토 후 승인

## 출력

카톡방에 사람이 직접 붙여넣을 수 있는(자동 전송 아님), 팀장근태/팀원근태로 구분되고 근태 종류별 인원수(소속팀 포함)가 표기된 요약 보고 텍스트 (최종 1개). App은 텍스트 생성까지만 담당하고, 카톡방 전송은 사람이 수동으로 한다.

---

## 제약

- 최종 발송·결재 같은 결정은 자동으로 하지 않고 사람이 확인한다
- 실행은 기본적으로 사람이 수동으로 하며, 사람이 실행하지 않은 경우에 한해 공휴일이 아닌 평일 오전 08:00에 자동 실행한다
