# Feature 4 명세 — 사람 확인(승인) 절차

근거 문서: [App_기획서.md](App_기획서.md) (12단계 — 사람 확인), [feature-1-spec.md](feature-1-spec.md), [feature-3-spec.md](feature-3-spec.md)

## 무엇을 하는 기능인가

Feature 1/3이 만든 근태 요약 텍스트를 화면에 그대로 보여주고, 사람이 터미널에서 y/n으로 확인(승인)하게 하는 기능. 승인해야만 최종 텍스트를 다시 보여주고, 거부하면 안내 문구만 출력하고 종료한다.

## 입력

- 근태 요약 텍스트 (Feature 1 또는 Feature 3가 만든 결과, 문자열 1개)

## 동작

1. 입력받은 요약 텍스트 전체를 화면에 그대로 보여준다. (민감 항목을 따로 가려내거나 강조하지 않고, 전체 내용을 사람이 직접 읽고 판단하게 한다.)
2. "이 내용을 카톡에 붙여넣어도 될까요? (y/n)" 안내와 함께 터미널 입력을 받는다.
3. y/n이 아닌 값을 입력하면 같은 질문을 다시 한다.
4. y(승인)면: 승인 완료 문구를 출력하고, 원본 요약 텍스트를 다시 한번 보여준다 (그대로 복사해서 쓰라는 의미).
5. n(거부)이면: "승인되지 않았습니다. 원본 근태 데이터를 확인한 뒤 다시 실행해주세요." 같은 안내 문구만 출력하고 종료한다.

## 출력

- 승인(y)한 경우: 승인 완료 문구 + 카톡에 그대로 붙여넣을 수 있는 최종 요약 텍스트
- 거부(n)한 경우: 안내 문구 1줄 (텍스트는 다시 보여주지 않고 종료)

## 지금은 뺄 것

- 거부 사유를 입력받거나 기록하는 것
- 민감 항목을 코드가 자동으로 판단해 강조 표시하는 것 (지금은 전체를 보여주고 사람이 직접 판단)
- 승인/거부 이력을 저장하거나 로그로 남기는 것
- 그래픽 화면 UI (지금처럼 터미널 텍스트 입출력까지만)
- 반복 재입력 횟수 제한이나 자동 취소 처리
